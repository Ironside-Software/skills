# Dart

## Checks

### dart/unawaited-future
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=async,errors instance-of=C-UNHANDLED-FAILURE-PATH
**What.** A `Future` is started and dropped: the caller continues before it completes, and its error becomes an uncaught zone error instead of reaching the surrounding `try`. `void f() async` functions have the same effect because callers cannot await them. **Signal.** Future-returning calls used as statements inside `async` bodies; `void ... async`; `Future` returned from a sync callback. **Confirm.** Enable `unawaited_futures`, `discarded_futures` and `avoid_void_async` in `analysis_options.yaml` (none are in `package:lints` recommended) and run `dart analyze`. **Not a finding when.** The call is wrapped in `unawaited(...)` from `dart:async` and the future handles its own errors.

### dart/late-read-before-init
meta: kind=defect safety=no default=on severity=correctness scope=cross pass=correctness tags=null-safety,lifecycle
**What.** A `late` field is read before it is assigned, or a `late final` is assigned twice; both throw `LateInitializationError` at runtime and the analyzer cannot see it for fields. **Signal.** `late` fields assigned only in a callback, a conditional branch, an `init()` method or another class. **Confirm.** Trace every read to an assignment that always happens first. **Not a finding when.** The field has an initializer (`late final x = compute();`, evaluated lazily on first read).

### dart/collection-identity-equality
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=equality,collections
**What.** `==` on `List`, `Map` and `Set` compares identity, so `[1] == [1]` is `false`; hand-written `operator ==` or `hashCode` over collection fields is therefore wrong. **Signal.** `==`/`!=` with a collection operand; `operator ==` comparing list fields directly; `hashCode => items.hashCode`. **Confirm.** `print([1] == [1]);` prints `false`. Use `DeepCollectionEquality`/`ListEquality` (`package:collection`) or `Object.hashAll`. **Not a finding when.** Both operands are the same canonicalised `const` literal, identity is intended, or the class is generated by `freezed`/`equatable`, which compare deeply.

### dart/decoded-json-cast
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=types,json
**What.** `jsonDecode` returns `List<dynamic>` and `Map<String, dynamic>`, so `as List<String>` or `as Map<String, int>` throws a `TypeError` even when every element has the right type. **Signal.** `as List<`, `as Map<String,` applied to decoded JSON or `response.data`. **Confirm.** `jsonDecode('["a"]') as List<String>` throws; `(x as List).cast<String>()` or `List<String>.from(x)` works.

### dart/dynamic-leak
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=types
**What.** Values typed `dynamic` (decoded JSON, untyped maps, `var` without an initializer) disable static checks: member calls compile and fail at runtime with `NoSuchMethodError`, and implicit downcasts from `dynamic` hide type errors. **Signal.** `dynamic` parameters or fields; method calls on `json['x']`; raw generic types (`List`, `Map`, `Future`). **Confirm.** Enable `avoid_dynamic_calls` and `language: strict-casts / strict-raw-types / strict-inference` (the `strong-mode: implicit-casts` section is deprecated) and run `dart analyze`.

### dart/subscription-not-cancelled
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=lifecycle,streams instance-of=C-USE-AFTER-DISPOSE
**What.** A `StreamSubscription` from `listen()` is never cancelled, or a `StreamController` is never closed, so callbacks keep firing after the owner is gone and the source stays referenced. **Signal.** `.listen(` whose result is not stored; stored subscriptions with no `cancel()` in `dispose`/`close`; `StreamController(` fields with no `close()`. **Confirm.** Lints `cancel_subscriptions` and `close_sinks`; read the owner's teardown method.

### dart/single-subscription-relisten
meta: kind=defect safety=no default=on severity=correctness scope=cross pass=correctness tags=streams
**What.** A single-subscription stream is listened to twice and throws `StateError: Stream has already been listened to`. **Signal.** `StreamController()` (not `.broadcast()`) whose `.stream` is exposed as a getter with several listeners; re-listening to `File.openRead()`, HTTP response streams or a stored `stream` after rebuilds. **Confirm.** Grep every listener of the getter; `stream.isBroadcast` tells which kind it is.

### dart/catch-error-handler-type
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=async,errors
**What.** The `Future<T>.catchError` handler must return a `FutureOr<T>`; a handler that only logs completes with `null` and throws at runtime for non-nullable `T`, and without `test:` it also catches programming errors. **Signal.** `.catchError((e) { log(e); })`, `.then(...).catchError(` on typed futures. **Confirm.** Analyzer warnings `body_might_complete_normally_catch_error` and `invalid_return_type_for_catch_error`; prefer `try`/`on` with `await`.

### dart/catch-without-on
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=errors instance-of=C-CATCH-ALL-SWALLOW
**What.** `catch (e)` with no `on` clause also catches `Error` subclasses (`TypeError`, `StateError`, `RangeError`, `LateInitializationError`), turning bugs into normal-looking results. **Signal.** `} catch (e) {` or `catch (_)` that returns a default, logs and continues, or maps to a user message. **Confirm.** Lints `avoid_catches_without_on_clauses` and `avoid_catching_errors`. **Not a finding when.** It is a top-level boundary (zone, isolate entry, request loop) that reports and rethrows or terminates.

### dart/unsafe-null-assertion
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=null-safety
**What.** `!` on a value that can be null throws `Null check operator used on a null value`. **Signal.** `map[key]!` with keys from input or server data; `!` on fields read after an `await`; `firstWhereOrNull(...)!`. **Confirm.** Show a path where the value is null. Private final fields are promotable since Dart 3.2, and an unneeded `!` there is reported as `unnecessary_non_null_assertion`. **Not a finding when.** A check in the same scope (`containsKey`, null test) establishes non-null.

### dart/local-datetime-at-boundary
meta: kind=defect safety=no default=on severity=correctness scope=cross pass=contracts tags=time,contracts instance-of=C-CONTRACT-DRIFT
**What.** `DateTime.now()` and `DateTime.parse` of a string without an offset produce local times; `toIso8601String()` on a local value omits the offset, so the receiver reads it in its own zone. **Signal.** `DateTime.now()` or `DateTime(...)` serialised to APIs or storage; `DateTime.parse` on server timestamps. **Confirm.** Check `isUtc` on the value that crosses the boundary, and the producer's format. **Not a finding when.** Values are converted with `.toUtc()` before serialisation or are deliberately local wall-clock values.

### dart/isolate-message-capture
meta: kind=defect safety=no default=on severity=correctness scope=local pass=correctness tags=isolates,concurrency
**What.** `Isolate.run`, `compute` and `Isolate.spawn` copy the closure and everything it captures; capturing `this` or an object holding a `ReceivePort`, `Socket`, `StreamController` or native handle throws `Invalid argument(s): Illegal argument in isolate message`, and large captures are copied on every call. **Signal.** Closures passed to `Isolate.run(`/`compute(` that reference fields or methods of the enclosing class. **Confirm.** `SendPort.send` docs list what may cross isolates; run the path. `Isolate.exit` transfers a result without copying.

## Duplication hotspots

- Number, currency, percent and date formatting: `package:intl` `NumberFormat`, `DateFormat`, `Intl.plural`.
- Collection helpers: `package:collection` (`DeepCollectionEquality`, `groupBy`, `sortedBy`, `mapIndexed`, `firstWhereOrNull`); `dart:core` `firstOrNull`, `lastOrNull`, `singleOrNull`, `nonNulls`, `indexed` (Dart 3.0).
- Hash combining: `Object.hash` / `Object.hashAll` (Dart 2.14) instead of hand-rolled prime arithmetic.
- Value types: records and patterns (Dart 3.0) instead of throwaway pair classes; the repo's `freezed`, `equatable` or `dart_mappable` models instead of hand-written `==`, `copyWith` and JSON code.
- Async utilities: `package:async` (`CancelableOperation`, `StreamGroup`, `StreamQueue`, `AsyncMemoizer`, `RestartableTimer`), `Completer`, `Stream.periodic`.
- Paths and URLs: `package:path` and `Uri` builders instead of string concatenation.
- Logging: `package:logging` or the repo's logger instead of `print`.

## Verification

- `dart analyze` (add `--fatal-infos` to see lints), `dart test`, `dart format --output=none --set-exit-if-changed .`, `dart fix --dry-run`.
- Read `analysis_options.yaml` first: the included set (`package:lints/recommended.yaml`, `flutter_lints`) decides which lints already run. Rule docs: `https://dart.dev/tools/linter-rules/<rule>`.
- Package sources: `~/.pub-cache/hosted/pub.dev/<package>-<version>/`, git dependencies under `~/.pub-cache/git/`; resolved versions in `pubspec.lock`; `.dart_tool/package_config.json` maps each package to its path.
- SDK sources: `<dart-sdk>/lib/` (`$(dirname $(readlink -f $(which dart)))/../lib`), or `<flutter>/bin/cache/dart-sdk/lib/` in Flutter projects. The language version is the `environment: sdk:` lower bound in `pubspec.yaml`.
- Generated code: `dart run build_runner build --delete-conflicting-outputs`.

## Not a finding

- Findings inside generated files (`*.g.dart`, `*.freezed.dart`, `*.mapped.dart`, `*.gr.dart`); report the annotated source instead.
- Futures deliberately detached with `unawaited(...)` whose errors are handled inside.
- `catch (e)` in tests asserting on the thrown value.
